# MaluStock

Controle de estoque dos cartuchos de tatuagem:

- **Estoque** — cartuchos na nomenclatura padrão — diâmetro (08, 10, 12), nº de agulhas e tipo, ex.: 10 07 RL, com aviso de estoque baixo
- **Saída · uso** — registra os cartuchos usados em cada sessão, com data e cliente
- **Entrada** — compras e reposições
- **Histórico** — o que foi usado, quando e em qual cliente; busca por cliente ou cartucho
- **Ajustes** — marcas, backup e exportação para Excel (.csv)

Os dados ficam só no aparelho (faça backup em Ajustes).

No iPhone: abra o link no Safari → Compartilhar → **Adicionar à Tela de Início**. Funciona sem internet depois de aberto uma vez.
